# 多兰古雷格地图志 · 黑魂2地图查看器

本项目为《黑暗之魂 2》（Dark Souls II）全境地图白模三维查看器小黑盒轻量版。全面收录游戏本体全部 **24 张核心地图**（如蜜、一线天森林、巨人陨落之森、海德巨火塔、密港、遗忘牢笼、流油谷、熔铁城、虚影森林、法洛斯门径、辉石镇、多兰古雷格王城、阿玛纳祭坛、不死灵庙、安第尔之馆、龙祭坛、巨人回忆、古龙回忆、暗潜古穴等），总计约 **450 万面三角形**。

参考黑暗之魂 1 地图小程序架构设计，并完整对接 [noclip.website](https://noclip.website/) 的 Dark Souls II 碰撞几何白模。

---

## 特性亮点

1. **原汁原味白模渲染（双模式切换）：**
   - **素模明暗模式：** 经典三维粘土白模渲染，配合双向主副光源漫反射、区域主题色彩微调与大气深度雾效，建筑结构与立体层次一览无余。
   - **线框模式：** 纯几何拓扑线框展现，便于深入研究关卡走线、隐秘通道与空间嵌套。
2. **第一人称真实碰撞漫步：**
   - 提取自 Havok 原版物理碰撞几何，直接作为地表判定面。
   - 支持重力加速度（19.0 m/s²）、台阶自动吸附爬升、跳跃翻越、障碍阻挡与跌落深渊保护。
3. **六自由度无拘飞行：**
   - 可一键随时在“漫步”与“飞行”之间无缝切换。飞行模式支持全自由穿透、独立升降控制与视线俯仰。
4. **全端双模操控体验：**
   - **移动端（手机 / 平板）：** 左手虚拟触控摇杆、右手独立滑屏视角、独立跳跃与升降按键、支持横屏全屏显示。
   - **桌面端（PC 键鼠）：** WASD / 方向键位平移、按住鼠标拖动调整视角、空格跳跃/上升、Q/E 升降、按住 Shift 疾跑加速。
5. **极速离线与体积控制：**
   - 全部 24 张地图经过 16 位整数差分编码与高效压缩，单图毫秒级即时解码。
   - 生产包约 **59 MB**（含 SDK、全量 24 图静态档案、UI 图标与交互逻辑），控制在平台 **100 MB** 限制以内。
6. **篝火出生点与无缝探索：**
   - 11 张地图的出生点依照游戏坐标落在篝火附近，并由原始碰撞面验证；其余区域使用经验证的安全落点（回忆和暗潜古穴没有常规篝火）。
   - 默认开启无缝探索，按玩家位置预载最多两张相邻地图；场景与碰撞体共同拼接，离开后卸载远处地图。可在设置中关闭。
   - 篝火坐标参考见 `scripts/bonfire-hints.json`，出生点见 `src/spawn-points.json`；修改后运行 `npm run prepare-maps` 重新生成地图包。

## 操控说明

| 操作动作 | 手机端触控 | 电脑键盘 / 鼠标 | 说明 |
| :--- | :--- | :--- | :--- |
| **移动 / 平移** | 左下角虚拟摇杆 | `W` / `A` / `S` / `D` 或 方向键 | 沿视线方向平移 |
| **视角旋转** | 屏幕空白区域滑动 | 按住鼠标左键拖动 | 俯仰角限制在 ±88° 以内防眩晕 |
| **模式切换** | 顶部“漫步 / 飞行”按钮 | — | 实时切换物理漫步或自由飞行 |
| **素模 / 线框** | 顶部“素模 / 线框”按钮 | — | 切换着色器明暗与网格线框 |
| **跳跃** | 右下角“跳跃”按键 | `Space`（空格键） | 漫步模式专用 |
| **上升 / 升高** | 右下角“升”按键 | `Space` 或 `Q` | 飞行模式专用 |
| **下降 / 降低** | 右下角“降”按键 | `E` | 飞行模式专用 |
| **疾跑 / 加速** | — | 按住 `Shift` | 移动速度提升至 2.2 倍 |
| **视线平视** | 顶部罗盘摆正按钮 | — | 一键将相机俯仰归零 |
| **重置位置** | 顶部重置按钮 | — | 迅速返回当前地图出生点 |
| **视野调整** | 设置面板内滑块 | — | 支持 50° ~ 105° 广角范围调节 |

## 本地开发与构建

```powershell
# 进入项目目录
cd miniapp-ds2

# 安装依赖
npm install

# 重新准备与打包地图静态资源（如源数据更新时）
npm run prepare-maps

# 运行自动化测试（数据完整性校验）
npm test

# 启动本地开发服务
npm run dev

# 生产环境打包（含类型检查与包体限额校验）
npm run build
```
